Prueba de API

Petición enviada a:
http://localhost:3000/registro

JSON enviado:
{
  "nombre": "Daniela",
  "mensaje": "Hola comunidad"
}

Respuesta del servidor:
{
  "estado": "Datos recibidos",
  "nombre": "Daniela",
  "mensaje": "Hola comunidad"
}

Explicación:
El servidor recibe los datos enviados en formato JSON y los devuelve en la respuesta para confirmar que fueron recibidos correctamente.
